# Integrations

## Slack

The Slack integration posts new ticket alerts to a channel and lets agents reply to tickets from Slack threads. Install it under Settings > Integrations > Slack. It requires a Slack workspace admin to approve the app.

## Shopify

The Shopify integration shows a customer's recent orders, order status and tracking links next to each ticket. It is available on the Growth and Enterprise plans.

## API and webhooks

The REST API lets you create, read and update tickets and contacts. API keys are created under Settings > Developers and are only shown once. The API is rate limited to 120 requests per minute per workspace. Webhooks can notify your server when a ticket is created, updated or closed, and each webhook request is signed with an HMAC-SHA256 signature header called X-Northwind-Signature.
